# 豫见河南（最短路径推荐系统）设计文档

- 日期：2026-03-04
- 项目定位：前端产品演示优先（录课展示）
- 技术路线：PC Web + Vue 3 + Vite + ECharts + 纯前端 Mock 数据

## 1. 目标与边界

### 1.1 目标
- 打造一个用于课程展示的“河南旅游智能推荐系统”前端产品原型。
- 重点体现完整产品体验链路：选点 -> 推荐 -> 路径 -> 行程输出。
- 算法作为背后能力，以“可解释、可视化、可演示”为主，不做学术化深挖。

### 1.2 范围
- 页面数：5 页。
- 终端：PC Web。
- 数据：纯前端本地 Mock JSON。
- 演示时长：10-15 分钟。

### 1.3 非目标
- 不接入真实后端。
- 不接入真实在线地图 SDK（采用伪地图拓扑图）。
- 不做复杂账号体系与运营后台。

## 2. 信息架构与页面职责

### 2.1 页面结构
1. 首页总览
2. 景点总览
3. 智能推荐
4. 路径详情
5. 行程结果

### 2.2 页面职责
- 首页总览：品牌表达、能力概览、快速开始。
- 景点总览：景点内容展示与筛选，强调美观与内容力。
- 智能推荐：用户输入偏好并生成候选路线。
- 路径详情：拓扑图展示最短路径结果与分段明细。
- 行程结果：输出最终可执行行程单。

### 2.3 导航与主链路
- 主导航：首页 | 景点总览 | 智能推荐 | 路径详情 | 行程结果
- 主链路：首页 -> 智能推荐 -> 路径详情 -> 行程结果
- 辅助链路：景点总览可“加入行程”并带参跳转智能推荐。

## 3. 视觉与交互（中国风硬约束）

### 3.1 视觉基调
- 风格：现代国潮 + 数据产品感。
- 必须中国风：中原文化识别清晰，但克制、现代、不堆砌。

### 3.2 色彩系统
- 黛青：主色（操作与强调）
- 朱砂/古铜金：品牌点缀
- 米白：页面底色
- 墨灰：正文与弱信息

### 3.3 视觉元素
- 山水渐变背景、浅纹理底、印章式局部图形。
- 卡片轻玻璃质感（弱透明 + 细描边）。
- 动效克制：缓动、短时长、避免炫技。

### 3.4 字体建议
- 标题：思源宋体（或同类高识别中文标题字体）
- 正文：思源黑体（或同类现代无衬线）

## 4. 技术架构

### 4.1 技术栈
- Vue 3
- Vite
- Vue Router
- Pinia
- ECharts

### 4.2 目录建议
- views/: 5 个页面
- components/: 景点卡、筛选栏、路线卡、时间轴、统计条
- data/: 城市、边、景点、规则
- stores/: 跨页状态（输入参数、推荐结果）
- utils/: 路径算法（Dijkstra）

## 5. 数据模型

- CityNode: { id, name, x, y }
- Edge: { from, to, distance, time, cost }
- Spot: { id, cityId, name, type, heat, season, score, image }
- UserPreference: { startCity, days, budget, tags[] }
- RouteResult: { cityPath[], spotPath[], totalDistance, totalTime, totalCost }

## 6. 算法落位（产品优先）

- 智能推荐页：根据偏好筛选候选景点/城市。
- 路径详情页：对候选城市图运行 Dijkstra，得到最短总距离路径。
- 行程结果页：按路径生成每日安排和费用汇总。

说明：算法展示以“结果可信 + 可视化可讲解”为目标，避免重数学推导。

## 7. 异常与回退

- 无推荐结果：提示条件过严，提供“一键放宽条件”。
- 图连通性不足：回退热门路线模板。
- 图片缺失：统一中国风占位图。
- 输入不完整：前端实时校验与中文提示。

## 8. 质量与验收

### 8.1 功能验收
- 5 页路由均可达。
- 智能推荐稳定产出 >= 2 条候选路线。
- 路径图与分段明细数据一致。
- 行程汇总计算正确（距离/时长/费用）。

### 8.2 展示验收
- 在 1366x768 与 1920x1080 下布局稳定。
- 中国风视觉一致，无风格漂移。
- 录课主链路 1 次走通无阻塞。

## 9. 录课演示脚本（10-15 分钟）

1. 项目定位与价值（1 分钟）
2. 首页 + 景点总览（3 分钟）
3. 智能推荐输入并生成候选（4 分钟）
4. 路径详情讲解最短路径支撑（3 分钟）
5. 行程结果收束（2 分钟）

## 10. 决策记录

- 采用方案：故事驱动型（产品演示优先）
- 增补页面：景点总览（美观展示页）
- 地图方案：伪地图拓扑图
- 数据策略：纯前端 Mock
- 终端形态：PC Web
