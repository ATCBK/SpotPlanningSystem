课程项目答辩

豫见河南旅游智能规划系统

基于最短路径思路的景点路线决策与可视化展示

演示目标

  • 把“选点到行程输出”形成完整闭环
  • 用可解释的路径推荐提升方案可信度
  • 在同等约束下给出更合理的路线建议
01 项目背景

问题从哪里来

旅游规划常见痛点

  • 景点分散，跨城市路线容易绕路
  • 人工规划很难同时平衡距离、时间、费用
  • 方案通常依赖经验，缺乏统一决策依据

项目要解决什么

  • 把路线选择从“主观判断”变成“有依据比较”
  • 输出可解释、可量化、可展示的推荐结果
  • 降低用户完成行程规划的决策成本

03 核心算法介绍

最短路径思路：先建模，再求解

建模方式

  • 城市抽象为节点，城市连接抽象为边
  • 用距离、时长、费用作为比较指标
  • 把旅游路线问题转化为图上的路径选择问题

求解逻辑

  • 确定起点、终点和必经点约束
  • 对每一段选择更优连接路径
  • 拼接各段结果，形成全局路线与总指标
03 核心算法介绍

为什么这条路径更可信

可解释性价值

  • 给出完整路径，而不是只给结论
  • 分段展示距离、时间、费用，便于对比
  • 当用户调整条件时，结果会同步更新

答辩表达建议

强调“我们不仅给路线，还给推荐依据”。

05 优劣势分析

方案评估

优势

  • 业务流程完整，展示链路清晰
  • 路线推荐有方法论支撑，非主观拍脑袋
  • 可视化表达强，适合课堂演示与答辩

可提升点

  • 策略维度还能扩展为多目标平衡
  • 复杂约束场景仍有优化空间
  • 个性化推荐能力可继续增强
06 未来改进方向

从课程演示走向可用产品

多目标优化

按距离优先、时间优先、费用优先输出不同方案。

个性化推荐

结合预算、兴趣、人群特征生成更贴合的路线。

场景扩展

扩充城市景点覆盖，提升方案在真实场景中的适用性。
